# E-Commerce Sales & Customer Analytics

## Objective
Analyze simulated e-commerce orders to study revenue drivers, profitability, customer segments, sales channels, discount levels and delivery performance.

## Tools
- Python: Pandas, NumPy, Matplotlib
- SQL: MySQL
- Power BI: dashboard design and KPI reporting

## Dataset
- 1,500 simulated transactions across 10 Indian cities and 6 product categories.
- Order dates: 1 January 2025 to 31 October 2026.
- The dataset is synthetic and created for portfolio practice. It is not real company or customer data.

## Files
- `ecommerce_sales_data.csv` - source dataset.
- `eda_analysis.py` - data profiling, KPI calculations, trend and segment analysis; exports a cleaned/augmented CSV.
- `analysis_queries.sql` - MySQL table definition and analytical queries.
- `powerbi_dax_measures.txt` - suggested DAX measures for a Power BI report.
- `analysis_summary.md` - calculated sample results with explicit synthetic-data caveats.
- `monthly_revenue_trend.png` and `category_revenue.png` - charts generated by the Python analysis.
- `resume_project_bullets.txt` - suggested resume wording.

## Run the Python analysis
1. Install dependencies: `pip install pandas numpy matplotlib`.
2. Keep `eda_analysis.py` and `ecommerce_sales_data.csv` in the same folder.
3. Run: `python eda_analysis.py`.
4. Review the console KPIs, `analysis_summary.md`, the generated `ecommerce_sales_cleaned.csv` and the chart PNG files.

## Load the data into MySQL
1. Create/select the database and run the `CREATE TABLE orders` statement in `analysis_queries.sql`.
2. Import `ecommerce_sales_data.csv` into `orders` using MySQL Workbench's Table Data Import Wizard. Ensure the CSV columns map in the same order as the table definition.
3. Run the analysis queries in `analysis_queries.sql`.

## Power BI report design
Recommended report pages:
1. Executive Overview - KPI cards, monthly revenue trend, revenue by category and city.
2. Product & Profitability - revenue/profit by category, margin and discount impact.
3. Customer & Channel - customer segment performance, channel mix and ratings.
4. Operations - delivery time, city performance and payment mix.

Suggested KPI measures are provided in `powerbi_dax_measures.txt`. Build and validate the dashboard in Power BI before claiming it as a completed dashboard project.

## Business questions
1. Which categories and cities generate the most revenue?
2. Which categories generate the highest profit margin?
3. Which sales channel performs best?
4. Which customer segment contributes the most revenue?
5. How do discount levels relate to revenue and profit margin?
6. How does revenue trend month over month?
7. How does delivery time vary across cities and channels?
